# AI First Backend Capstone

An AI-powered web application that accepts user prompts through a web interface and returns AI-generated responses using a backend REST API.

## Project Overview

This project demonstrates how to build a small AI-powered application with a separate frontend and backend.

The frontend collects the user's question and sends it to the FastAPI backend. The backend validates the input, calls the OpenAI API, handles errors, and returns the generated answer as JSON.

## Technology Stack

- **Backend:** Python 3, FastAPI
- **Frontend:** HTML5, CSS3, JavaScript
- **AI Integration:** OpenAI API
- **Request Validation:** Pydantic
- **API Documentation:** OpenAPI / Swagger UI
- **Dependencies:** pip and `requirements.txt`
- **Version Control:** Git and GitHub
- **Deployment Goal:** AWS

## Application Architecture

```text
User
  |
  v
Frontend (HTML, CSS, JavaScript)
  |
  | HTTP POST /api/chat
  v
FastAPI Backend
  |
  | Validate prompt
  v
OpenAI API
  |
  | Generated response
  v
FastAPI Backend
  |
  | JSON response
  v
Frontend displays answer
```

The frontend and backend have separate responsibilities. The frontend handles user interaction, while the backend manages validation, AI integration, and error handling.

## Features

- Interactive web interface for submitting questions.
- REST API endpoint for AI-powered responses.
- JSON request and response handling.
- Input validation and prompt length limits.
- OpenAI API integration.
- Error handling for missing credentials and provider failures.
- Health check endpoint.
- Automatic API documentation through FastAPI.
- Environment-based API key configuration.

## API Endpoints

### 1. Home

**GET /**

Returns the frontend HTML page.

### 2. Health Check

**GET /health**

Example response:

```json
{
  "status": "ok"
}
```

### 3. AI Chat

**POST /api/chat**

Accepts a prompt and returns an AI-generated answer.

Request body:

```json
{
  "prompt": "What is FastAPI?"
}
```

Successful response:

```json
{
  "success": true,
  "answer": "FastAPI is a Python web framework for building APIs."
}
```

The actual answer is generated by the configured AI model and may differ from this example.

### Error Handling

The API uses appropriate HTTP errors for common failures:

- **422 Unprocessable Entity:** Invalid or missing prompt.
- **503 Service Unavailable:** Missing AI API configuration.
- **502 Bad Gateway:** AI provider request failure.

## Installation and Setup

### Step 1: Clone the repository

```bash
git clone https://github.com/deva1986/ai-first-backend-capstone.git
cd ai-first-backend-capstone
```

### Step 2: Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Configure the API key

Set the `OPENAI_API_KEY` environment variable.

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="your-api-key"
```

macOS or Linux:

```bash
export OPENAI_API_KEY="your-api-key"
```

Optionally, configure the model using the `OPENAI_MODEL` environment variable. The application defaults to `gpt-4.1-mini`.

Never commit actual API keys or other secrets to GitHub.

### Step 5: Run the application

```bash
uvicorn app:app --reload
```

### Step 6: Open the application

Frontend:

http://127.0.0.1:800
